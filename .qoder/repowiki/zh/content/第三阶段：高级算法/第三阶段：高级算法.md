## 架构总览
回溯框架由“选择—探索—撤销”三要素构成，配合剪枝条件形成高效搜索。下图展示通用回溯流程与各题解模块的关系。

```mermaid
flowchart TD
Start(["开始"]) --> Init["初始化路径/状态"]
Init --> Choose["做出选择<br/>更新状态"]
Choose --> Check{"满足终止/剪枝条件？"}
Check --> |是| Record["记录结果"]
Check --> |否| Explore["递归探索下一层"]
Explore --> Undo["撤销选择<br/>恢复状态"]
Undo --> Next["尝试下一个候选"]
Next --> Choose
Record --> End(["结束"])
```

## 详细组件分析

### 组合问题：组合总和 II（去重与目标值剪枝）
- 关键思路
  - 先对候选数组排序，便于同层去重与提前剪枝
  - 使用 start 索引保证每个元素在同一组合中仅用一次
  - 同层去重：若当前元素与前一个相同且前一个未被使用于同一层，则跳过
  - 目标值剪枝：当剩余目标和小于 0 时直接返回
- 复杂度
  - 时间：最坏 O(2^n)，实际受剪枝影响显著降低
  - 空间：递归深度 O(n)，结果不计入空间复杂度
- 可视化参考
  - 参见学习材料中的状态树与剪枝示意

```mermaid
sequenceDiagram
participant Caller as "调用方"
participant BT as "回溯函数"
Caller->>BT : "传入候选数组、起始索引、目标和、路径"
BT->>BT : "判断是否达到目标和"
alt 达到目标
BT-->>Caller : "保存当前路径"
else 未达目标
loop 遍历候选
BT->>BT : "同层去重检查"
BT->>BT : "目标值剪枝检查"
BT->>BT : "选择当前元素并更新状态"
BT->>BT : "递归进入下一层"
BT->>BT : "撤销选择恢复状态"
end
end
```

### 组合问题：组合（基础组合）
- 关键思路
  - 从 n 个数中选 k 个，start 控制选择范围
  - 路径长度等于 k 时记录结果
  - 可结合上界剪枝减少无效分支
- 复杂度
  - 时间：O(C(n,k))
  - 空间：O(k) 递归栈
- 可视化参考
  - 参见学习材料中的组合树展开

```mermaid
flowchart TD
A["开始"] --> B["选择范围[start..n]"]
B --> C{"路径长度==k?"}
C --> |是| D["记录路径"]
C --> |否| E["遍历i从start到n"]
E --> F["选择i，start=i+1"]
F --> G["递归"]
G --> H["撤销选择"]
H --> E
D --> I["结束"]
```

### 子集问题：子集（无重复）
- 关键思路
  - 每个位置可选择“加入”或“不加入”，形成二叉决策树
  - 每层将当前路径加入结果集合
- 复杂度
  - 时间：O(2^n)
  - 空间：O(n) 递归栈
- 可视化参考
  - 参见学习材料中的子集树

```mermaid
flowchart TD
S["开始"] --> L["当前位置index"]
L --> R["记录当前路径"]
R --> J{"index < n ?"}
J --> |否| X["结束"]
J --> |是| T1["选择nums[index]"]
T1 --> Rec1["递归index+1"]
Rec1 --> U1["撤销选择"]
U1 --> T2["不选择nums[index]"]
T2 --> Rec2["递归index+1"]
Rec2 --> U2["撤销选择"]
U2 --> X
```

### 子集问题：子集 II（含重复元素）
- 关键思路
  - 先排序，再在同层跳过与前一个相同且未被使用的元素
  - 其余与子集一致
- 复杂度
  - 时间：O(2^n)，去重后有效分支减少
  - 空间：O(n)
- 可视化参考
  - 参见学习材料中的去重分支对比

```mermaid
flowchart TD
S["开始"] --> Sort["排序输入"]
Sort --> DFS["回溯(index, path)"]
DFS --> Add["记录path"]
Add --> Loop["for i in [index..n-1]"]
Loop --> Skip{"i>index 且 nums[i]==nums[i-1] ?"}
Skip --> |是| Loop
Skip --> |否| Pick["选择nums[i]"]
Pick --> Rec["DFS(i+1, path+[nums[i]])"]
Rec --> Unpick["撤销选择"]
Unpick --> Loop
```

### 排列问题：全排列（含重复元素）
- 关键思路
  - 使用 visited 标记已选元素；同层去重需保证“前一个相同元素在本层未被使用”
  - 也可用交换法原地生成，但去重要谨慎处理
- 复杂度
  - 时间：O(n·n!)
  - 空间：O(n)
- 可视化参考
  - 参见学习材料中的排列树与去重点

```mermaid
flowchart TD
S["开始"] --> DFS["回溯(path, used)"]
DFS --> Done{"len(path)==n ?"}
Done --> |是| Save["保存path"]
Done --> |否| For["for i in [0..n-1]"]
For --> Used{"used[i] ?"}
Used --> |是| For
Used --> |否| Dup{"i>0 且 nums[i]==nums[i-1] 且 not used[i-1] ?"}
Dup --> |是| For
Dup --> |否| Pick["选择i，used[i]=true"]
Pick --> Rec["DFS(path+[nums[i]], used)"]
Rec --> Unpick["used[i]=false"]
Unpick --> For
```

### 分割问题：回文分割
- 关键思路
  - 以起始位置为状态，尝试所有可能的切割点
  - 每次切出的子串必须为回文才继续递归
  - 可用双指针或预计算表加速回文判断
- 复杂度
  - 时间：最坏指数级，取决于回文约束强度
  - 空间：O(n) 递归栈
- 可视化参考
  - 参见学习材料中的分割树与回文校验

```mermaid
flowchart TD
S["开始(start=0)"] --> Try["for end in [start..n-1]"]
Try --> Pal{"s[start..end]是回文？"}
Pal --> |否| Try
Pal --> |是| Pick["加入段s[start..end]"]
Pick --> Rec["回溯(end+1)"]
Rec --> Unpick["撤销段"]
Unpick --> Try
```

## 性能考虑
- 剪枝优先
  - 排序后利用单调性进行上界/下界剪枝（如目标和剪枝）
  - 同层去重避免重复分支
- 状态设计
  - 明确“选择—探索—撤销”的最小状态集，避免冗余拷贝
- 预处理
  - 回文判断可预计算二维表，将单次判断降至 O(1)
- 输出规模
  - 注意结果数量本身可能呈指数级，评估内存与时间开销

## 故障排查指南
- 常见错误
  - 忘记撤销选择导致路径污染
  - 同层去重条件写错（应基于“前一个相同元素在本层未被使用”）
  - 未排序导致去重失效
- 调试建议
  - 打印当前路径与选择索引，观察状态变化
  - 在小规模输入上逐步验证剪枝逻辑
  - 对照学习材料的可视化步骤定位异常分支
