本模块按目标 Agent 平台分目录组织，每个目录承载该平台可识别的 skill 或运行时配置：
- `.claude/settings.local.json`：Claude Code 的本地权限白名单，显式允许 Bash（python/npx/find/rmdir/claude）、WebSearch 以及对 `~/.claude` 和 `~/.config/claude` 的读取。
- `.gemini/skills/continuous-learning/`：Gemini CLI 的 skill 包，包含 SKILL.md（声明 name/description/origin 等 frontmatter）、config.json（最小会话长度、提取阈值、忽略模式等）以及 evaluate-session.sh（作为 Claude Code 的 Stop hook 脚本，通过 stdin JSON 中的 transcript_path 解析会话消息数并输出评估信号）。
- `.trae/skills/find-skills/SKILL.md`：Trae 的 find-skills skill，引导 agent 使用 `npx skills` 生态搜索并安装第三方 skill。
依赖方向单向：各平台的 skill 仅被对应宿主读取，evaluate-session.sh 只读 stdout/stdin 与文件系统，不反向修改宿主配置。
