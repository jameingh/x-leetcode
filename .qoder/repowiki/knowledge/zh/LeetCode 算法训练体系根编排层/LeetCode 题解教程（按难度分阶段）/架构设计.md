目录即课程大纲：`stage1/` 为入门三件套（linked_list、sliding_window、two_pointers），`stage2/` 进入进阶（bfs、binary_search、binary_search_tree、binary_tree），`stage3/backtracking/` 与 `dp/` 为组合搜索与动态规划专题。每个子目录对应一类题型，文件名采用「英文题目名_数字题号.py」格式，便于通过题号快速定位。每道题是独立可执行的 Python 脚本：文件内自包含本地节点类（ListNode / TreeNode）与 Solution 类，并通过 `if __name__ == "__main__"` 块内联构造多组测试用例打印验证；模块之间无相互 import，依赖方向仅单向指向标准库（typing、collections.deque）。注释以中文为主，穿插“思维模型”图示与 TODO 提示，体现教学引导风格。
