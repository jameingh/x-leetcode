本仓库是一个 LeetCode 算法训练与学习笔记集合，不包含任何构建系统或自动化流水线。具体表现为：

- **无构建脚本**：仓库中不存在 Makefile、build.sh、Dockerfile、docker-compose.yml、CI/CD 配置（.github/workflows）等任何构建相关文件。
- **无依赖管理**：没有 requirements.txt、pyproject.toml、setup.py、go.mod、Cargo.toml、package.json 等依赖声明文件；所有题解均为独立 Python 脚本，直接通过 `python3 <file>` 运行。
- **无测试框架**：每个题解文件内嵌 `if __name__ == "__main__":` 块进行简单 print 验证，未使用 pytest、unittest 等测试框架。
- **无打包发布流程**：仓库定位为个人学习与 AI 协作练习，不涉及包发布、容器化或部署。

该仓库的“执行方式”完全基于 Python 解释器直接运行单个 .py 文件，属于教学/笔记型仓库的典型形态，无需传统意义上的构建系统。
