# 第三阶段：决策空间的博弈艺术 —— 回溯搜索 (Backtracking)

如果说前面的算法是教你如何“高效地走一条路”，那么回溯算法就是教你如何**“系统性地穷举所有可能的路”**。它是解空间搜索的核心，是理解动态规划和复杂搜索算法的敲门砖。

## 1. 核心思维：决策树与“吃后悔药”

回溯算法的本质是 **深度优先搜索 (DFS)** 的一种特例。它的核心在于在一个巨大的“决策树”上进行探索。

**思维模型：迷宫探险**
你在一个分岔路口众多的迷宫里找出口：
1. **决策**：你在每个路口都要做一个决定——往左走、往右走还是往前走？
2. **深入**：你选择一条路（比如向左），并记录下你已经走过的路径。
3. **触底/撞墙**：
   - 没找到目标？你必须回到上一个路口，并**抹掉你刚才在那条死路上留下的足迹**（这就是“回溯”）。
   - 找到目标？记录答案，然后可能还要回到路口找寻下一个可能的答案。

**核心公式：路径 + 选择列表 + 结束条件**

## 2. 回溯三要素（必背模板）

写回溯算法就像是在填空，你只需要把下面的模板刻在大脑里：

```python
def backtracking(路径, 选择列表):
    if 终止条件:
        结果.append(path[:]) # 注意：在 Python 中通常要深拷贝一份当前路径
        return

    for 选择 in 选择列表:
        # 1. 做选择 (将该选择从列表中移除/标记，并加入路径)
        路径.append(选择)
        
        # 2. 递归 (进入下一层决策树)
        backtracking(路径, 缩小后的选择列表)
        
        # 3. 撤销选择 (核心！把路径恢复原状，把刚才的选择放回选择列表)
        路径.pop()
```

## 3. 为什么需要“撤销选择”？

想象你在做“排列组合”题。你第一层选了数字 `1`。
- 如果不回溯，当你从深层递归回来准备尝试选数字 `2` 时，你的路径里还残留着之前的 `1`。
- **回溯（pop）的意义就是保持“案发现场”的绝对干净**，让每一层主管在做决定时，看到的都是相同的初始环境，而不是被前一个分身污染过的残局。

## 5. 学术语对照

| 大纲关键词 | 我们的实战模型 | 对应代代码中的动作 |
| :--- | :--- | :--- |
| **路径 (Path)** | **已走过的路** | 递归函数中的 `path` 列表，记录了当前的决策序列。 |
| **选择列表** | **岔路口** | `for` 循环遍历的范围，代表当前有哪些路可以走。 |
| **剪枝 (Pruning)** | **提前知道没戏** | 在 `for` 循环中加入 `if` 判断，提前 `continue` 掉那些明显不会出结果的分支。 |
