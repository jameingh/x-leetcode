# 第三阶段：决策空间的博弈艺术 —— 回溯搜索 (Backtracking)

如果说前面的算法是教你如何“高效地走一条路”，那么回溯算法就是教你如何**“系统性地穷举所有可能的路”**。它是解空间搜索的核心，是理解动态规划和复杂搜索算法的敲门砖。

## 1. 核心思维：决策树与“吃后悔药”

回溯算法的本质是 **深度优先搜索 (DFS)** 的一种特例。它的核心在于在一个巨大的“决策树”上进行探索。

**思维模型：迷宫探险**
你在一个分岔路口众多的迷宫里找出口：
1. **决策**：你在每个路口都要做一个决定——往左走、往右走还是往前走？
2. **深入**：你选择一条路（比如向左），并记录下你已经走过的路径。
3. **触底/撞墙**：
   - 没找到目标？你必须回到上一个路口，并**抹掉你刚才在那条死路上留下的足迹**（这就是“回溯”）。
   - 找到目标？记录答案，然后可能还要回到路口找寻下一个可能的答案。

**核心公式：路径 + 选择列表 + 结束条件**

## 3. 大脑模拟案例 (Brain Simulation)：n=3, k=2

为了不让代码显得抽象，我们在脑子里跑一下 `combine(3, 2)` 的过程：

1. **第一层递归 (start=1)**：
   - 选 `1`：`path=[1]`。**进入下一层 (start=2)**。
2. **第二层递归 (start=2)**：
   - 选 `2`：`path=[1, 2]`。长度达到 `k=2`！**记录并返回**。
     > **💡 [重要细节] 拍照存证：必须用 `path[:]` 或 `path.copy()`**
     > **否则 `result` 里存的只是同一个 `path` 对象的引用，回溯完会全变空。**
     > 
     > 伪代码：
     > ```python
     > if 终止条件:
     >     结果.append(path[:]) # 或者 结果.append(list(path)) 或 结果.append(path.copy())
     >     return
     > ```
   - **回溯**：`path.pop()` -> `path=[1]`。
   - 选 `3`：`path=[1, 3]`。长度达到 `k=2`！**记录并返回**。
   - **回溯**：`path.pop()` -> `path=[1]`。
   - 这层没得选了，返回上一层。
3. **回到第一层 (start=1)**：
   - **回溯**：`path.pop()` -> `path=[]`。
   - 选 `2`：`path=[2]`。**进入下一层 (start=3)**。
4. **第二层递归 (start=3)**：
   - 选 `3`：`path=[2, 3]`。长度达到 `k=2`！**记录并返回**。
   - **回溯**：`path.pop()` -> `path=[2]`。
   - 这层没得选了，返回。
5. **回到第一层 (start=1)**：
   - **回溯**：`path.pop()` -> `path=[]`。
   - 选 `3`：`path=[3]`。**进入下一层 (start=4)**。
6. **第二层递归 (start=4)**：
   - `4 > n`，直接退出。

**确定性选择**：你会发现，`startIndex` 就像是给你划了一道“不准回头”的警戒线。选了 `1` 就只能从 `2` 往后看；选了 `2` 就只能从 `3` 往后看。这直接剪掉了所有重复的分支！

## 4. 为什么需要“撤销选择”？

想象你在做“排列组合”题。你第一层选了数字 `1`。
- 如果不回溯，当你从深层递归回来准备尝试选数字 `2` 时，你的路径里还残留着之前的 `1`。
- **回溯（pop）的意义就是保持“案发现场”的绝对干净**，让每一层主管在做决定时，看到的都是相同的初始环境，而不是被前一个分身污染过的残局。

## 4. 行动指南：从组合到排列

回溯算法非常讲究“套路”，我们将通过两类最经典的题目作为切入点：
1. **[77. 组合]** - 掌握“集合内选择”的逻辑，理解如何通过参数 `startIndex` 来防止重复选择。
2. **[46. 全排列]** - 掌握“元素顺序相关”的搜寻，理解如何利用 `used` 数组或交换法来控制决策空间。

## 5. 学术语对照

| 大纲关键词 | 我们的实战模型 | 对应代代码中的动作 |
| :--- | :--- | :--- |
| **路径 (Path)** | **已走过的路** | 递归函数中的 `path` 列表，记录了当前的决策序列。 |
| **选择列表** | **岔路口** | `for` 循环遍历的范围，代表当前有哪些路可以走。 |
| **剪枝 (Pruning)** | **提前知道没戏** | 在 `for` 循环中加入 `if` 判断，提前 `continue` 掉那些明显不会出结果的分支。 |
