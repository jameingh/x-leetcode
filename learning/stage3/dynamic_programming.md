# 动态规划 (Dynamic Programming) 引导笔记

> 核心心法：**"答案拼装"**——当前问题的答案，可以由更小子问题的答案直接组装出来。

---

## 一、如何识别 DP 题型

当题目出现以下信号时，优先考虑动态规划：

1. **求"方案总数"**：有多少种方法爬到楼顶？有多少条不同路径？
2. **求"最优值"**：最大收益、最小花费、最长长度。
3. **不要求列出所有具体方案**：只要一个数字作为答案。

对比回忆：如果题目要你**列出每一条具体路径**（如 77. 组合），那是回溯的领地；如果只要**数量或极值**，DP 往往能把指数级的搜索压缩成线性复杂度。

---

## 二、核心思维锚点：DP 三步走

### 第 1 步：定义状态
问自己："`dp[i]` 这个格子里存的是什么？"
- 爬楼梯：`dp[i]` = 到达第 i 级台阶的方法数。
- 状态定义是 DP 的地基，定义错了后面全崩。

### 第 2 步：写转移方程
问自己："`dp[i]` 的最后一步，有哪几种来源？"
- 爬楼梯的最后一步：要么从 i-1 跨 1 步，要么从 i-2 跨 2 步。
- 所以 `dp[i] = dp[i-1] + dp[i-2]`。

### 第 3 步：确定起点与推导方向
问自己："最小的、不需要拼装就知道答案的子问题是什么？"
- 爬楼梯：`dp[1] = 1`，`dp[2] = 2`。
- 然后从小到大，一格一格填表。

---

## 三、大脑模拟：爬楼梯 (n = 5)

| 台阶 i | 决策逻辑 | dp[i] |
|--------|---------|-------|
| 1 | 起点，只能跨 1 步 | 1 |
| 2 | 起点，1+1 或直接跨 2 | 2 |
| 3 | dp[2] + dp[1] = 2 + 1 | 3 |
| 4 | dp[3] + dp[2] = 3 + 2 | 5 |
| 5 | dp[4] + dp[3] = 5 + 3 | 8 |

每一格都不需要重新思考"路线长什么样"，只需要把前两格的答案加起来。这就是 DP 与暴力搜索的本质区别：**小答案只算一次，永久复用**。

---

## 四、DP 与回溯的关系

| 维度 | 回溯 | 动态规划 |
|------|------|---------|
| 目标 | 列出所有解 | 求方案数 / 最优值 |
| 思维方向 | 从上往下走决策树 | 从小往大填表 |
| 复杂度 | 通常指数级 | 通常线性或平方级 |
| 三要素 | 路径 + 选择列表 + 结束条件 | 状态定义 + 转移方程 + 起点 |

一句话：回溯是"亲自走遍每条路"，DP 是"只记每个路口的统计结果"。

---

## 五、通用解题步骤（模板节奏）

1. 读题，确认是"数量/极值"型问题。
2. 定义 `dp[i]` 的含义（用一句完整的中文说出来）。
3. 分析"最后一步"的来源，写出转移方程。
4. 填好起点（最小子问题）。
5. 从小到大循环填表，返回目标格子。

## 七、进阶招式：滚动变量（空间优化）

当转移方程只依赖**前固定几格**时（如爬楼梯只看前两格），整个 dp 数组可以退化为几个变量滚动前进，就像走路时只需记住左右两只脚的位置，不需要记住每一个脚印。空间从线性降为常数。

### ⚠️ 经典陷阱：覆盖丢失

错误写法（旧值被提前覆盖，导致每轮翻倍）：

```python
curr = prev + curr   # curr 的旧值在这里就丢了
prev = curr          # 拿到的是新 curr，两个变量永远相等
```

正确写法一（临时变量，跨语言通用）：

```python
temp = prev + curr   # 覆盖之前先保值
prev = curr
curr = temp
```

正确写法二（Python 原子交换，右边先整体求值再赋值）：

```python
prev, curr = curr, prev + curr
```

核心钢印：**覆盖之前先保值**。

### ⚠️ 陷阱二：“串票”（配对错位）

滚动变量把下标压缩掉之后，`curr`（即 dp[i-1]）与 `prev`（即 dp[i-2]）和各自费用项的配对关系只存在于脑子里，很容易拿错：

```python
# 错误：站在 i-2 的人付了 i-1 台阶的票钱
curr = min(prev + cost[i-1], curr + cost[i-2])

# 正确：钱跟着起跳的台阶走
curr = min(curr + cost[i-1], prev + cost[i-2])
```

核心钢印：**钱跟着起跳的台阶走**——从 i-1 起跳就配 cost[i-1]，从 i-2 起跳就配 cost[i-2]。

逆向自检信号：求最小花费的题算出**比正确答案还便宜**的结果，说明有路径在“逃票”；答案偏离的方向本身就是定位 bug 的线索。
